# 业务术语说明

本文件用于解释业务人员在自然语言问题中可能使用的简称、行业术语或内部口语。Agent 在理解问题时应将这些说明与数据库字段说明一起使用。

| 业务术语 | 本题含义 |
|---|---|
| 战区 | 门店所属区域，对应 `dim_store.region` |
| SKU | 一个具体商品，对应 `dim_product.product_id`，展示时通常同时给出商品名称 |
| 销额 | 默认指成交销额，即 `quantity × sale_price - discount_amount` |
| 即时零售 | 销售渠道 `channel_code = 'O2O'` |
| 到店 | 销售渠道 `channel_code = 'POS'` |
| 团购 / 企业团购 | 销售渠道 `channel_code = 'B2B'` |
| 动销 | 某 SKU 在指定范围内产生了实际销售；如果问题说“动销最好并按销额排序”，则按成交销额排名 |
| 退损 | 退款造成的金额损失，对应 `refund_amount` |
| 退损率 | 指定范围退款金额 / 指定范围成交销额 |
| 放量 | 某商品或门店在后一时期的销量或销额明显增加 |
| 毛利拖累 | 某些低毛利商品占比上升，使整体毛利率下降 |
| 商品结构 | 不同 SKU / 品类在整体销量或销额中的构成 |

如果用户使用术语而数据库中没有同名字面字段，应优先通过本说明寻找业务含义，再确定实际字段和查询条件，而不是仅做字段名相似度匹配。
